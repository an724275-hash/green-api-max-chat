## Запуск и live-проверка

Node.js 24.15+ в ветке 24 или 26+. В green_api_chat: npm ci, npm run dev; открыть адрес из Vite. Демо запускается кнопкой без ключей. npm run check выполняет lint/types/unit/build; npm run test:e2e требует Chromium либо CHROMIUM_PATH для Edge (команды в README).

Для live пользователь самостоятельно вводит idInstance, apiTokenInstance и apiUrl в локальную форму. Ключ скрыт и хранится в памяти вкладки. Нужен отдельный авторизованный тестовый MAX-инстанс, HTTP API без webhookUrl/других потребителей, входящие уведомления и согласный тестовый получатель. Проверить номер, вручную отправить уникальный текст, подтвердить доставку на телефоне, ответить в MAX и увидеть ответ в клиенте. Проверить восстановление сети без повторной отправки и пустую новую сессию после выхода. Не включать ключи, частные сообщения и URL DevTools в скриншоты или архив.

Контракт номера и chatId повторно сверен с [CheckAccount](https://green-api.com/v3/docs/api/service/CheckAccount/), поля send и лимит 4000 с [SendMessage](https://green-api.com/v3/docs/api/sending/SendMessage/). Эти проверки документации не подтверждают живую интеграцию. Прошлый отчёт сохранён в VERIFICATION-2026-10-03.md.
