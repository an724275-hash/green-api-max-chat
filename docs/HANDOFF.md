# Проверить и отправить задание

Проект подготовлен с AI-помощью (AI-assisted). Локальные проверки и демо пройдены; реальная доставка и ответ в MAX ещё не проверены. Интерфейс принят пользователем 4 октября 2026.

## 1. Открыть приложение

Текущий preview на этом ПК: **http://127.0.0.1:5180/**. Если сервер уже остановлен, в папке проекта выполнить:

```bash
npm ci
npm run dev
```

Открыть адрес, который покажет Vite. Кнопка «Посмотреть демо без ключей» запускает локальную имитацию; метка «Демо» в шапке поясняет режим по наведению или нажатию. Сообщения из демо не отправляются в MAX.

## 2. Проверить настоящий MAX

1. В кабинете GREEN-API подготовить отдельный тестовый инстанс MAX и авторизовать его. Для HTTP API очистить webhookUrl, включить incomingWebhook, outgoingAPIMessageWebhook и outgoingWebhook. Другие потребители его очереди должны быть остановлены. Подробности в README.
2. Самостоятельно ввести idInstance, apiTokenInstance и apiUrl из кабинета в локальную форму. Не отправлять ключ помощнику или работодателю, не добавлять его в Git, архив, .env или скриншоты. Нажать «Подключиться».
3. Ввести номер своего тестового аккаунта или согласного получателя (+7 либо +375), нажать «Создать чат».
4. Отправить уникальный короткий текст. Убедиться на телефоне получателя, что он дошёл. Ответить из приложения MAX на телефоне и проверить, что ответ появился в браузере.
5. Проверить текст с emoji и новой строкой, восстановление получения после краткого отключения сети, затем выход и пустую новую сессию. При неопределённой отправке сначала проверить телефон, а затем решать о ручном повторе.

«В очереди» означает принятие API, а не подтверждённую доставку. Для задания нужен фактический обмен с телефоном; демо и HTTP-моки его не заменяют. Если live-проверка не пройдена, честно указать это при сдаче.

## 3. Подготовить письмо

По оригинальному PDF задания:

- Получатель: **hr@green-api.com**.
- Тема: **Тестовое задание на должность - Фронтенд разработчик React**.
- Приложить своё резюме в PDF; указать Telegram для связи.
- Репозиторий: https://github.com/an724275-hash/green-api-max-chat
- Инструкция: https://github.com/an724275-hash/green-api-max-chat/blob/main/README.md#быстрый-запуск
- Скриншоты: https://github.com/an724275-hash/green-api-max-chat/tree/main/docs/screenshots
- Указать предпочтительный формат: удалёнка / офис Химки / офис Астана.
- Ссылка на сервис в интернете желательна, но не обязательна. Локальный localhost не является такой ссылкой; деплой не выполнялся.

ZIP можно приложить дополнительно, но он не заменяет обязательную ссылку GitHub. Снимки в репозитории показывают только пустую форму и демо, без реальных ключей и переписки. Письмо отправляет пользователь самостоятельно; автоматической отправки нет.
